How to Convert to PNG

To convert the SVG logos to PNG format with custom dimensions, you can use the provided Python script:

This will generate PNG versions in multiple sizes (256x256, 512x512, 1024x1024, and 2048x2048 pixels). The PNG files will be saved in a 'png' folder with transparent backgrounds.
