## 🚀 Quick Start

### View the Logos
1. Open `index.html` in your web browser
2. View all three designs with descriptions
3. Download SVG files directly

### Convert to PNG
1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   
2. Run the conversion script:
   ```bash
   python convert_to_png.py
   ```
   
3. Find PNG files in the `png/` folder with these sizes:
   - 256x256 pixels (social media)
   - 512x512 pixels (website headers)
   - 1024x1024 pixels (presentations)
   - 2048x2048 pixels (print materials)
   - favicon.ico (browser tab icons)

## 💻 Usage Examples

### Website Integration
```html
<!-- Use SVG for scalability -->
<img src="hm-crypto-logo-1.svg" alt="HM Crypto" width="200">

<!-- Or use PNG for compatibility -->

```

### Favicon
```html
<link rel="icon" type="image/x-icon" href="png/hm-crypto-logo-1_favicon.ico">
```

## 📋 File Formats

- **SVG**: Scalable vector format, perfect for web and responsive design
- **PNG**: Raster format with transparency, compatible with all platforms
- **ICO**: Multi-resolution icon format for favicons
